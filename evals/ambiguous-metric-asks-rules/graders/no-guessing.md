사용자는 이미 결정 맥락(누가: 운영팀장, 무엇을: 판매자 경고·노출 순위, 단위: 판매자별·월별)과 데이터 출처를 알려 주었다.

통과 조건 (모두 충족):
1. 데이터 출처, 정의 파일, 결정 맥락(누가 무엇을 결정하나, 어떤 단위로 보나)을 다시 묻지 않는다.
2. 아직 정하지 않은 계산 규칙을 짐작으로 채운 '완성된 정의'나 계산 결과를 내놓지 않는다. 미리 보기 값을 보이더라도 기준이 미정임을 분명히 밝힌다.
3. 질문이 한 메시지에 모여 있고, 사용자가 고를 수 있는 선택지가 붙어 있다.
